In Azure Portal go to:
- Static Web App (e.g. "agis-filio-wedding-buses-gr")
- Go to "Settings / Custom Domains"
- Select "Add" and select "Custom domain on other DNS"
- Insert the desired sub-domain (e.g. "gr-buses.ourwedding-agis-filio.org")
- In the section "Validate + add" set the "Hostname record type" to "TXT" and use the "Generate Code" button
- Copy the code generated into a draft notepad
- In Cloudflare Dashboard, select the main domain (e.g. "ourwedding-agis-filio.org")
- The go to DNS and hit "Add record":
	Type = TXT
	Name = the prefix included in the domain (e.g. "gr-buses")
	Content = (paste the code generated by Azure above)
	TTL = Auto
- Back from Azure Portal, from Static Web App's "Overview" tab, copy the full default domain without the "https://" prefix (e.g. "brave-island-0e32e1703.7.azurestaticapps.net")
- Back in Cloudflare in the "Settings / Custom Domains", add a new record of "CNAME" type:
	Type = CNAME
	Name = the prefix included in the desired sub-domain (e.g. "gr-buses")
	Target = value copied from the full default domain of the azure web app, without the "https://" (e.g. "brave-island-0e32e1703.7.azurestaticapps.net")
	Proxy Status = DNS only
	TTL = Auto
